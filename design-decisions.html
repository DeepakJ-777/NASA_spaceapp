Design record · Phase 2 · 15 November 2026

A listening desk for the planet

The dashboard provides the Phase 2 structure. It is clear about what is a placeholder and what the next phase must add.

Brief

Purpose

For hackathon visitors who want to understand Earth rainfall through sight and sound. They arrive curious, before any live data is loaded.

Character

A quiet observation console beside a listening station, not a cinematic spacecraft control room.

Feel

Measured, credible, and inviting. The team should look careful with scientific source material.

Richness

One rich observation area and restrained supporting controls. The visualization is the reason to visit, so the rest stays quiet.

Scope: one responsive dashboard screen in operate mode.

Screens: 320 px to 1600 px, from the request for desktop and mobile support.

First value: visitors can immediately see the planned Earth view, select the only honest dataset option, and understand the sound mapping.

Signature moment: the observation window and the audio player directly below it.

Ending: visitors finish with a short explanation of precipitation, sonification, and pitch.

Constraints: no NASA API, no invented measurement, and no audio generation in this phase.

Assumed, please correct: the first audience is a mixed hackathon crowd, not trained Earth scientists.

Direction

Chosen: Quiet telemetry. Thin coordinates, a measured grid, square controls, and a cyan signal color suggest careful observation without pretending that the screen contains live mission data.

It beat cinematic orbit, which would add too much glow and spectacle, and data laboratory, which would make the first visit feel too technical.

The provisional identity uses a small orbital sound mark, narrow uppercase naming, deep navy, and one clear cyan signal color.

Design language

PartDecision and reason
VoiceShort and factual. Placeholder limits are stated where visitors need them.
TypeNarrow system display type for planetary scale; regular system text for easy reading without a font download.
SpaceWide around the observation area, compact inside controls. This separates exploration from operation.
ColorDeep navy surfaces with cyan for signal and selection. Green is reserved for readiness status.
ShapeSquare panels and controls keep the screen close to scientific equipment. The Earth and brand mark earn the only circles.
ControlsNative select, range, and buttons keep keyboard behavior. A two-pixel cyan focus ring stays visible.
MechanicsOne unlayered src/index.css file owns all styles. No library or inline style system competes with it.
MotionNo decorative motion in Phase 2. Hover and focus feedback are immediate. Reduced motion is respected.

Use over time

The screen is the honest empty state for Phase 2. It does not need network loading, offline, error, or signed-out states because no service exists yet. Long text wraps, keyboard focus is visible, touch controls are at least 42 pixels high, and the layout stacks on narrow screens.

For you to decide

  • Confirm the primary audience before scientific terms become more detailed.
